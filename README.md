# Atividade de Versionamento - SENAI

Projeto desenvolvido durante o curso de **Programador Full Stack do SENAI**, com o objetivo de praticar os fundamentos de versionamento de código utilizando **Git e GitHub**.

## 📚 Sobre o projeto

Nesta atividade foram praticados conceitos fundamentais de controle de versão, incluindo:

- Criação e configuração de repositório Git;
- Adição e acompanhamento de arquivos;
- Criação de commits;
- Utilização de branches;
- Integração e resolução de conflitos;
- Envio de alterações para o GitHub;
- Prática de comandos Git pelo terminal.

## 🛠️ Tecnologias e ferramentas

- Git
- GitHub
- Terminal / Git Bash

## 🎯 Objetivo

Desenvolver conhecimentos básicos de versionamento de código e compreender o fluxo de trabalho com Git e GitHub, preparando a base para projetos de desenvolvimento de software.
